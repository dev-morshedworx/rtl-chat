# rtl-chat

Draws chat messages right-to-left whenever the message text is Arabic (at least 30% of its letters are Arabic script). It keeps markdown formatting (bold, lists, headings) and code blocks, and makes lines that start with an English word read right-to-left too. English messages keep the normal left-to-right drawing. Applies to both your messages and Claude replies. Install it once as a plugin and it works in every session, with no setup or options needed.

Install: `/plugin install rtl-chat --marketplace <owner>/<repo>`
