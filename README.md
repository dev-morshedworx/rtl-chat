# rtl-chat

Draws chat messages right-to-left whenever the message text is Arabic (at least 30% of its letters are Arabic script). English messages, and any message containing a code block, keep the normal left-to-right drawing and markdown formatting. Applies to both your messages and Claude's replies. Install it once as a plugin and it works in every session, with no setup or options needed.

Install: `/plugin install rtl-chat --marketplace <owner>/<repo>`
